# Drop4Life

> **"Every Drop Can Save a Life."**

A centralized blood donation management and emergency blood coordination platform connecting donors, hospitals, and NGOs. Features rule-based donor matching, emergency request tracking, 8-group blood inventory management, interactive compatibility tools, and campaign coordination.

## 👥 Core User Roles

1. **Donor:** View compatible urgent requests, manage donation history, update availability, and track lifesaving impact.
2. **Hospital:** Create emergency blood requests, manage 8-group blood inventory, match compatible donors, and coordinate transfusions.
3. **NGO:** Organize community blood donation campaigns, coordinate public blood drives, and mobilize local donors.

## 🛠️ Technology Stack

- **Framework:** Next.js (App Router) + TypeScript
- **Styling:** Tailwind CSS + Custom Healthcare Design System
- **Icons & UI:** Lucide Icons + Accessible UI components
- **Forms & Validation:** React Hook Form + Zod
- **Analytics:** Recharts
- **Maps:** Leaflet & OpenStreetMap
- **Testing:** Vitest & Playwright
